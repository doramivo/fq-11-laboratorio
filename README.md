# FQ 11.º ano: aceleração e 3.ª Lei de Newton

Material interativo para explicações de Física e Química A (11.º ano).

- `index.html`: laboratório com quatro simulações (carro na estrada, bola lançada para cima, patinadores no gelo, pares ação-reação) e o roteiro de uma sessão de 1 h.
- `exercicios.html`: dez exercícios que se corrigem sozinhos, com dica, resolução passo a passo e «Novos números» para gerar outra versão.

Não precisa de instalação: são páginas HTML estáticas, sem dependências.

## Publicar no GitHub Pages

1. Cria um repositório novo no GitHub (por exemplo `fq-11-laboratorio`), público.
2. Carrega `index.html`, `exercicios.html` e este `README.md` para a raiz do repositório (botão **Add file → Upload files**).
3. Em **Settings → Pages**, escolhe **Deploy from a branch**, branch `main`, pasta `/ (root)`, e guarda.
4. Ao fim de um ou dois minutos o site fica em `https://<o-teu-utilizador>.github.io/fq-11-laboratorio/`.
